# YAB Ghana Board biographies: public editorial notes

Research updated 31 October 2026. The website contains eleven Board member portraits, all stored locally under `assets/img/portraits/`. All Board biography text and supporting links are in `js/site.js`. The live administrator can submit an approved revision of any individual biography from the Level 1 dashboard.

Profiles should continue to be reviewed by Board members for consent, title changes and public-identity consistency. The YAB roster uses **Davis Akua Effah Kaufmann** and **George Nartey-Wayo**, while some professional sources use shorter or reordered names. Do not change these without confirming with the individuals.

Private records, contact information, financial details and other restricted documents are not part of the public website or this repository.
